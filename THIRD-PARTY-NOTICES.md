# Third-party notices

## Fluent System Icons

2891 assets in `assets/icons/system/` are derived from
[Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) by Microsoft,
used under the MIT licence. The Outline and Mono artwork is unmodified except for a
rewrite of `#212121` to `currentColor` so it can take a Windows accent.

The Standard variant of those assets is **not** Fluent artwork. It is generated by
`scripts/import-fluent.mjs`, which insets the filled Fluent glyph in a gradient tile.
Each affected asset says so in its `notes` field.

Every asset also carries a `source` block in its `meta.json` naming the upstream
project, its licence, and a link to the original.
