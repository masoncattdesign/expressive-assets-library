An asset library that tools can read

Expressive Assets is the icon and illustration library for Windows Design Systems, together with the tools built on top of it. This page is the way in: what it is, what the tools do, and where the working documents are.

How it works, in short

Artwork is designed in Figma, imported through a reviewed plan, and stored as flat SVG with metadata beside it. A build step turns that tree into one file, manifest.json, and everything downstream reads only that.

That single rule is what makes the rest possible. A tool never walks the asset folders, so adding a collection, a style or a size changes nothing in the tools. It is also why a new tool takes an afternoon rather than a sprint. The System Map draws the whole thing end to end.

The tools

Gallery Live Browse and search the whole library. Filter by collection, style and size, preview against light and dark, copy or download any drawing. Customizer Live Apply an icon style across a set of twelve at once and tune it: palette, stroke, texture, surface. Any slot swaps for anything in the library.
Builder Later Compose illustrations from reusable pieces. Waits on the illustration cleanup and an agreed illustration style.

Every asset is published, and 1,836 of the 14,808 individual drawings are marked generated: produced here to complete a style-by-size matrix rather than received as artwork. Status is a property of the asset and provenance is a property of the variant, so the two are kept apart. All 88 File Icons and all 28 M365 Illustrations carry a Standard that was imported and an Outline and Filled derived from it; 19 Product Icons have size cells that were scaled or derived to square the matrix.

Published means the drawing is real, not that its id is final. The naming grammar is still open, and 2,665 ids carry a hyphen inside a name segment that Bridge's scheme does not allow. Those ids will change.

The documents

Includes where the library stands and the decisions still open. Asset Anatomy How the parts inside an icon are named, marked and addressed, with the artwork taken apart panel by panel. The work in progress right now, and the piece that makes the Customizer stop guessing.

The full working notes behind Asset Anatomy, including all twelve pilot icons and the measurements, are in the Icon Anatomy Pilot.

These are working drafts rather than published specifications, and they are written to be argued with. Where something is undecided they say so, and the open questions at the end of each are genuinely open. If one of them is wrong, that is worth more to me than if it is agreed with.
