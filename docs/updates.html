Two things the round trip depends on are now measurable

  • npm run naming:report measures every id against Bridge's naming rule and prices both ways of conforming, so the decision has a number attached instead of a feeling.
  • npm run figma:probe checks whether the REST API actually returns the shared plugin data the pull half of the round trip is designed around. That assumption has never been tested, and everything else waits behind it.

1 September 2026 Library · 2.0

Third party, app tiles, and a contract break

This one changes manifest.json in a way a consumer has to notice. Group entries carry an id and no longer map one to one onto type, and the asset field placeholders became generated and widened to mark any drawing produced here rather than received.

  • 61 third-party brand marks imported at 32px, not recolorable, every one attributed.
  • 32 Windows app tiles imported into their own collection at 64px.
  • M365 Illustrations replaced: the 28 at 160px are gone, 40 new ones at 512px are in.
  • File Icons became a top-level group and lost Filled. What shipped as Filled was derived rather than drawn and nothing upstream has one, so 799 drawings were deleted.
  • The library stands at 3,234 assets and 14,114 drawings, 980 of them flagged generated.

Worth knowing: published means the drawing is real, not that its id is final. The naming grammar is still open and those ids will change.

1 September 2026 Figma

The sync plugin had never once run its layout pass

A sync that created nothing also laid out nothing, so on a file that already had cards the card layout silently did not run. It looked like a styling problem for three runs. The plugin now runs in Node against a fake Figma, both shipped bugs were put back to confirm the harness catches them, and npm run test:plugin is the gate before pressing sync on a real file.

The plugin writes. Nothing reads back yet, and that is the next substantial piece of work.
