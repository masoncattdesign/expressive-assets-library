Open decisions

  • 12px sizesA real size for all 90 Product Icons, or off the 12 that carry one. A 12px icon is a different drawing, not a small one.
  • Illustration stylesWhether Outline and Filled get derived for the 512px M365 set. Worth deriving one and looking at it together first.
  • System icon gapsGenerate over the sizes Fluent does not ship, or leave the collection honest about what exists.
  • Naming grammar2,698 ids carry a hyphen inside a name segment that Bridge's scheme disallows. Either the ids change or the grammar does.
  • Third-party marks61 brand marks are imported and on a public URL. A license review is outstanding.
  • AccessGitHub Pages has no access control. The Azure Static Web Apps path is written out and parked.
