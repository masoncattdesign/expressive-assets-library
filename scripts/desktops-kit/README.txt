Desktop prototypes: Workbench, Mosaic and Pinboard

How to open
1. Unzip the folder.
2. Open index.html in Edge or Chrome (double-click it).
3. Pick a desktop. Press 1, 2 or 3 to jump between them, and T to change the
   theme (or use the Theme switch in the pill at the top).

Everything on each desktop responds, so click, drag and type freely.

Workbench: pull the gooey cards and let go, type in Ask Copilot, open the
Lisbon itinerary to watch the center take over, or open Stacks.
Mosaic: tap Show me on the Copilot banner, click an empty + slot, or use
"Shaped by Copilot" at the bottom left to have Copilot build a row of tiles.
Drag any tile into an open slot.
Pinboard: drag any widget or sticker around, press the + in the bottom bar,
and ask Copilot to "make it cozy for fall" or "calm night mode".

Themes: every desktop has Default (as designed) and Sketch. Workbench and
Pinboard add Comic strip, Mosaic adds Neon, Pinboard adds Stipple and Texture. The illustrations are real pieces from the
Windows illustration library, restyled per theme.

These are explorations, not product. All content is made up.
Best viewed on a large screen; each desktop scales to fit the window.

Building on these with Claude? CLAUDE.md in this folder explains how they
work; Claude Code reads it automatically when you open the folder.
